Reports a format string whose placeholders do not match the arguments that follow it. 

io::printfn("status=%s body=", code, body);   // too many arguments: 1 placeholder, 2 arguments
io::printfn("status=%s body=%s", code);       // too few arguments: 2 placeholders, 1 argument

For a function or macro marked @format(n) (io::printfn, string::tformat, DString.appendf, log::info) the compiler rejects a mismatch, so it is shown as an error. Format functions without the attribute, such as io::eprintfn, are not checked by the compiler; a parameter String format or String fmt directly followed by args... is recognised as a format string and a mismatch is a warning. At run time a missing argument prints <MISSING> and an extra argument is dropped.

%% is a literal percent sign, and a * width or precision (%*d) takes an argument of its own. Only a format written as a string literal is checked, and only when the arguments are written out (no ...splat).
