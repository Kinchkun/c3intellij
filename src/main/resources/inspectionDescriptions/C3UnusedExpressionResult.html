Reports statements that compute a value and then throw it away — for example calling a function whose return value is never stored, returned or otherwise used. The Create local variable quick fix rewrites expression; as Type name = expression;, inferring the type and a snake_case name when possible and otherwise letting you type them.

Statements written for their side effect are not reported: assignments, increments (x++), optional-unwraps (mayFail()!) and explicit (void) discards. A call is reported only when its callee resolves to a function with a non-void return type that is not annotated @maydiscard.
