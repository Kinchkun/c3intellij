Reports a member access receiver.member whose member does not exist on the receiver's type — for example calling a method that is not declared on a struct. 

struct Object { int x; }

fn void f(Object* object)
{
    object.this_method_does_not_exist(); // 'this_method_does_not_exist' is not a method or field of Object
}

To avoid false positives the inspection is conservative: it only reports when the receiver's type is known and is a struct/union with at least one field. Slices, arrays, enums and other built-in types (whose members such as .len, .ptr or .ordinal are not indexed) are not checked, and neither are accesses through a call result (foo().bar) or a Type::ident scope access.
