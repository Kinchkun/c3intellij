Reports a plain name used as a value that is not declared, as the compiler does ("'respons' could not be found, did you spell it right?"). 

fn HttpResponse execute()
{
    HttpResponse response;
    return respons; // 'respons' could not be found
}

Only an unqualified lower-case name inside a function, macro or lambda body is checked: it must be a local, a parameter, a declaration of the same module or a @builtin of the standard library. The inspection needs the standard library to be indexed and stays quiet without it. A name that is declared anywhere in the project or its libraries is not reported either.

The quick fix Change to '…' is offered for locals, parameters and declarations of the same module whose name is at most two edits away.
